# TLA+ Model Header Block

Every `model/base.tla` generated by Phase 3 should begin with a comment
block in this shape before the `MODULE` declaration, so the model is
self-describing without needing `generation-log.md` open alongside it:

```tla
------------------------------ MODULE base ------------------------------
(* Generated by traceproof-poc — Phase 3 (Model Generation)
   Scenario: <scenario text, or "module-scoped: <module name>">
   Derived from knowledge files:
     - knowledge/<module-a>.md
     - knowledge/<module-b>.md
   Generated: <ISO-8601 timestamp>
   Self-repair attempts this run: <n>
*)
============================================================================
```

Within the body, every non-trivial invariant or guard condition should carry
an inline comment pointing back to the knowledge file it came from, e.g.:

```tla
\* Source: knowledge/payments.md — "a payment can't be marked successful
\* until the transaction is confirmed"
Inv_PaymentRequiresConfirmation == ...
```

This keeps the model traceable back to plain-language facts a human can
check, without requiring the human to read TLA+ to verify the *intent* is
right (mirrors the project's plain-English sign-off principle even though
this POC itself doesn't implement the sign-off UI).
